# PES 6 DualShock 3 Input Remapper Profile

This repository contains my personal controller configuration for playing **Pro Evolution Soccer 6 (PES 6)** on Linux using a **DualShock 3 (PS3)** controller via **Input Remapper 2**.

## 🎮 Features
- Mapped perfectly to emulate the classic PES 6 keyboard/gamepad layout.
- Plug-and-play config for native Linux installations of Input Remapper.

## 📂 Installation Location
To use this preset, copy the `.json` file to your local configuration folder:
```bash
~/.config/input-remapper-2/presets/Sony PLAYSTATION(R)3 Controller/
```

## 🛠️ Requirements
- Linux OS
- Input Remapper 2 (Native Version)
- DualShock 3 Controller
